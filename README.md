# Money Tracker (flat PWA files)

Everything is in ONE folder level, no sub-folders. Upload ALL 8 files to the main page (root) of your GitHub repo:

index.html, manifest.json, sw.js,
icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png, favicon-48.png

If a file with the same name already exists, GitHub replaces it. Then wait 1-2 minutes and test in PWABuilder with your link.
Test the icon first: open https://YOUR-USERNAME.github.io/icon-192.png in Chrome. It must show the logo.
